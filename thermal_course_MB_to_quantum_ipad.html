0. 先看懂这节课到底在解决什么

这不是一堆互不相关的公式。课件实际上在回答一个问题：微观粒子怎样分布，为什么会产生我们测到的宏观热学量？

总主线：微观状态概率 → 最大概然分布 → 速度/位置分布 → 平均能量 → 内能与热容 → 经典理论与实验矛盾 → 量子理论。
① 为什么平衡态对应最大熵？ ② 配分函数为什么能“装下”热力学信息？ ③ MB分布如何变成麦克斯韦速度分布？ ④ 有外场时为什么空间分布不均匀？ ⑤ 为什么一个自由度平均是 kBT/2？ ⑥ 自由度如何决定热容？ ⑦ 固体热容为什么又需要量子？ ⑧ 紫外灾难为什么暴露经典理论？ ⑨ 离散能级怎样改变分布？

本课最值得记住的 6 个公式

S = k_B ln Ω
P_i = exp(-βE_i) / Z，　Z = Σ_i exp(-βE_i)，　β = 1/(k_B T)
f(v) ∝ v² exp[-mv²/(2k_B T)]
n(r) ∝ exp[-φ(r)/(k_B T)]

1. 熵：为什么平衡态是“最概然”的？

课件首先把热力学第二定律换成微观语言：在平衡态，系统的微观状态可以看作等概率；而宏观状态之所以稳定，是因为它对应的微观实现方式最多。

1.1 微观状态数 Ω 与熵

S = k_B ln Ω

这里 Ω 是满足给定宏观条件的微观状态数。因为对数把“状态数的乘法”变成“熵的加法”，所以熵具有正确的可加性。

直觉：不是“系统喜欢无序”，而是“对应于宏观平衡态的微观实现方式极多”。因此随机演化时，落在这些宏观状态的概率远大于落在少数特殊状态的概率。

1.2 为什么平衡态熵最大？

设宏观状态 A 对应 Ω_A 个微观态，状态 B 对应 Ω_B 个微观态。若 Ω_A ≫ Ω_B，那么随机选取一个微观态时，出现 A 的概率远大于 B：

P(A) / P(B) = Ω_A / Ω_B

所以大量粒子体系一旦离开平衡态，通常会自发走向微观状态数更多的区域，即熵增加。

第二定律的微观图像：从非最大概然分布走向最大概然分布；在这个自发过程中，熵增加。
考试陷阱：“熵最大”不是说每个微观态的概率不一样。恰恰是在孤立平衡系统中，可能微观态等概率，而某个宏观分布之所以最可能，是因为它包含的微观态最多。

2. 配分函数：从微观概率直接得到宏观量

课件随后引入配分函数。它的核心意义不是“背一个 Z”，而是：Z 是所有允许微观能量状态的统计权重之和。

2.1 从玻尔兹曼因子到概率

平衡态中，能量为 E_i 的状态权重正比于：

w_i = e^{-βE_i}

概率必须归一化，因此把所有状态的权重加起来：

Z = Σ_i e^{-βE_i}

于是：

P_i = e^{-βE_i}/Z

2.2 为什么 β = 1/(kBT)？

β 必须把能量 E 变成无量纲指数。温度提供的能量尺度就是 k_B T，因此：

β = 1/(k_B T)

温度升高时 β 变小，高能态受到的指数惩罚减弱；温度降低时 β 变大，系统更集中在低能态。

2.3 Z 为什么这么重要？

课件给出平均能量与 Z 的关系：

U = ⟨E⟩ = - ∂(ln Z)/∂β

推导：

ln Z 对 β 求导 = (1/Z) Σ_i (-E_i)e^{-βE_i} = - Σ_i E_i P_i = -⟨E⟩

所以：

⟨E⟩ = -∂lnZ/∂β
学习策略：遇到“求平均能量、热容”等问题，可以先想“能不能求 Z”。Z 是统计力学里的总账本。

3. 从 MB 最大概然分布到麦克斯韦速度分布

这是本课最重要的推导之一。一定要分清三个对象：

速度空间分布
描述 v_x、v_y、v_z 怎么分布。
速率分布
描述速率 v=|v| 怎么分布，注意会多出 v²。

3.1 理想气体的单粒子能量

理想气体分子没有相互作用势能，因此：

E = p²/(2m) = (p_x²+p_y²+p_z²)/(2m)

玻尔兹曼因子：

e^{-βE} = e^{-βp_x²/(2m)} e^{-βp_y²/(2m)} e^{-βp_z²/(2m)}

关键：三个方向完全因子化，所以三个动量分量彼此独立。这正是后来能量均分定理成立的基础之一。

3.2 为什么得到高斯分布？

对 p_x 而言，概率密度必须与：

e^{-βp_x²/(2m)}

成正比。归一化后利用高斯积分：

∫_{-∞}^{∞} e^{-a x²} dx = √(π/a)

得到单方向动量分布：

f(p_x)=√[β/(2πm)] exp[-βp_x²/(2m)]

速度满足 p_x=mv_x，因此：

f(v_x)=√[m/(2πk_B T)] exp[-mv_x²/(2k_B T)]

3.3 从三维速度分布到速率分布：为什么出现 v²？

三维速度空间中，速率介于 v 和 v+dv 的所有速度点位于一个球壳中。球壳体积：

dV_v = 4πv² dv

而三维分布只依赖 v²，所以乘上球壳体积后：

f(v)dv = 4π (m/(2πk_BT))^{3/2} v² exp[-mv²/(2k_BT)] dv
考试最容易错的地方：指数项来自能量；v² 来自三维球壳的几何简并。不要把 v² 当成“凭空多出来的”。

3.4 三个典型速度

量结果怎么理解
最概然速率 v_p√(2k_BT/m)使 f(v) 最大的速率
平均速率 ⟨v⟩√(8k_BT/(πm))对 v 做加权平均
均方根速率 v_rms√(3k_BT/m)由 ⟨v²⟩ 得到

三者关系：

v_p < ⟨v⟩ < v_rms

4. 玻尔兹曼密度分布：外场为什么让气体“不均匀”？

4.1 重力场：先做最熟悉的例子

高度 z 处的重力势能：

φ(z)=mgz

等温条件下，气体满足理想气体方程 p=nk_BT。力学平衡要求：

dp/dz = -nmg

代入 p=nk_BT，并且 T 恒定：

k_BT dn/dz = -nmg

整理：

dn/n = -(mg/(k_BT)) dz

积分：

ln n = -mgz/(k_BT)+constant

所以：

n(z)=n(0)e^{-mgz/(k_BT)}
物理图像：越高势能越大，玻尔兹曼因子越小，因此粒子数密度随高度指数下降。

4.2 推广到任意势场

课件把重力场推广到一般外势 φ(r)。平衡时：

∇p = -n∇φ

等温理想气体满足 p=nk_BT，因此：

k_BT∇n = -n∇φ

于是：

∇ln n = -(1/(k_BT))∇φ

积分得到玻尔兹曼密度分布：

n(r)=n_0 exp[-φ(r)/(k_BT)]
一句话：经典平衡系统中，位置能越高，粒子出现的统计权重越低，权重由 e^{-φ/kBT} 控制。

4.3 旋转系统为什么会出现类似现象？

课件以回转体、龙卷风、台风、离心机为例。旋转参考系中可以用有效势能描述离心效应，因此粒子空间分布仍可写成玻尔兹曼型指数。重点不是背具体例子，而是会把“势能 → 分布”这一模板迁移。

5. 麦克斯韦—玻尔兹曼分布：速度和位置其实是同一个故事

课件明确区分：

分布控制变量权重
麦克斯韦分布动量/速度e^{-E_k/(k_BT)}
玻尔兹曼分布位置e^{-E_p/(k_BT)}

如果粒子无相互作用，而且总能量可以写成：

E = E_k + E_p

那么：

e^{-E/(k_BT)} = e^{-E_k/(k_BT)} e^{-E_p/(k_BT)}
核心统一视角：动能控制“速度怎么分”，势能控制“位置怎么分”；二者在无相互作用、可分离的情况下统计独立。

6. 能量均分定理：为什么一个自由度平均得到 ½kBT？

6.1 什么叫自由度？

课件定义：决定物体位置和状态所需的独立坐标。对分子而言，可以分成平动、转动和振动自由度。

模型典型自由度课件强调
单原子质点33个平动
刚性双原子53平动+2转动
非刚性双原子7再加入1个振动的两个能量项
非线性三原子9个构形自由度3平动+3转动+3振动模式
注意：振动模式不是简单地“一个自由度只贡献一次”。一个简谐振动包含动能和势能两个二次型，因此经典极限下一个完整振动模式平均贡献 k_BT。

6.2 平动自由度的详细推导

x方向平动能量：

E_x = p_x²/(2m)

其概率分布正比于 e^{-βp_x²/(2m)}。平均能量：

⟨E_x⟩ = [∫(p_x²/2m)e^{-βp_x²/(2m)}dp_x] / [∫e^{-βp_x²/(2m)}dp_x]

利用高斯积分的结果，可以得到：

⟨p_x²⟩ = m/β = mk_BT

因此：

⟨E_x⟩ = ⟨p_x²⟩/(2m) = ½k_BT

y、z方向完全相同，所以：

⟨E_trans⟩ = 3/2 k_BT

6.3 转动自由度

转动动能形式也是二次型：

E_rot = L²/(2I)

在经典统计极限下，每个独立的转动二次型同样贡献：

½k_BT

因此刚性双原子分子的两个转动自由度贡献 k_BT。

6.4 振动自由度：为什么是 kBT 而不是 ½kBT？

简谐振动：

E_vib = p²/(2m_eff) + ½kx²

这里有两个二次型：

平均动能 = ½k_BT；　平均势能 = ½k_BT

所以一个完整振动模式：

⟨E_vib⟩ = k_BT
统一记忆：“一个独立二次型 → ½kBT”。振动有动能二次型+势能二次型，所以一个振动模式 → kBT。

7. 从自由度直接算理想气体内能和热容

7.1 内能

课件把准理想气体理解为只有粒子热运动动能、忽略粒子间相互作用势能。若每个分子有效贡献 f 个二次型自由度：

U = (f/2)Nk_BT = (f/2)nRT

7.2 定容热容

定义：

C_V = (∂U/∂T)_V

若 f 在该温度范围内不变：

C_V = (f/2)nR

摩尔定容热容：

C_{V,m} = (f/2)R

7.3 典型结果

气体模型f（有效二次型）CV,m
单原子理想气体33R/2
刚性双原子55R/2
双原子振动充分激发77R/2

7.4 混合气体：不要直接平均摩尔热容

若两种气体质量分别为 M_1、M_2，摩尔质量为 μ_1、μ_2，则摩尔数：

n_1=M_1/μ_1，　n_2=M_2/μ_2

总定容热容是各组分热容之和：

C_V,total = n_1 C_{V,m,1} + n_2 C_{V,m,2}

混合物摩尔热容：

C̄_{V,m} = C_V,total/(n_1+n_2)
易错：不能简单做 (C_1+C_2)/2，除非两种气体的物质的量恰好相同。

7.5 为什么实验告诉我们经典理论“不完整”？

课件指出：经典理论在固定自由度模型下预测热容与温度无关，但实验显示热容随温度变化。随着温度升高，自由度逐渐被激发：低温主要平动，常温开始出现转动，高温振动逐渐参与。

历史转折：经典统计认为能量连续，所以自由度应随时均分；实验却显示某些自由度在低温“沉默”。这要求引入量子理论中的离散能级。

8. 固体热容：杜隆—珀替定律与经典极限

固体中原子被束缚在晶格附近，没有自由平动和整体转动，主要表现为晶格振动。

每个原子可近似看作三个方向的简谐振子。每个方向有动能和势能两个二次型：

每个方向平均能量 = k_BT

三个方向：

⟨E⟩ = 3k_BT

因此一摩尔固体在经典高温极限：

C_{V,m} ≈ 3R

这就是杜隆—珀替定律的核心结果。课件指出，室温下很多固体符合得不错，但很硬的固体如金刚石偏离明显，于是需要 Einstein 单模模型和 Debye 多模模型来处理量子化振动。

9. 黑体辐射与“紫外灾难”：经典统计在哪里崩了？

课件把辐射场看成许多单色平面波的叠加，并统计不同频率的电磁场自由度。

9.1 经典思路

每个自由度按能量均分得到：

平均能量 ∼ k_BT

而频率越高，可容纳的电磁模式数越多。瑞利—金斯理论因此预测高频端能量密度随频率快速增加。

9.2 矛盾

实验并没有看到高频能量无限增加。经典理论预测在紫外区域发散，这就是著名的紫外灾难。

与前面的气体热容问题是同一种危机：经典“连续能量+均分”在高频/低温等情况下给出了与实验不符的结果。

解决方向是量子化：振动模式不能任意吸收任意小的能量，而必须按离散能量量子交换。

10. 量子气体简介：离散能级、全同性、自旋、不确定性

10.1 离散能级

课件用“楼房”类比：系统是楼房，楼层是能级，每层房间是量子态，每层房间数是简并度。

E_1,E_2,E_3,... 是离散的；某能级可能包含 g_i 个量子态。

因此经典连续积分，在离散能级问题中往往变成对能级的求和。

10.2 全同性

量子粒子可能不能像经典粒子那样通过“给粒子编号”来区分。相同粒子的交换不会产生新的物理状态。

粒子交换性质核心规则
玻色子波函数交换对称不受泡利不相容原理限制
费米子波函数交换反对称服从泡利不相容原理

10.3 自旋

课件强调自旋是粒子的内禀性质，不能简单理解成“小球绕自身旋转”。自旋量子数为整数时对应玻色子，半整数时对应费米子。

10.4 海森堡不确定性原理

Δx Δp ≥ ħ/2

其核心不是“仪器不够精密”，而是量子态本身不能同时具有任意精确的位置和动量。

10.5 离散能级下为什么仍然得到 MB 形式？

课件最后从碰撞过程的细致平衡出发。热平衡要求某个能级“撞入”的宏观概率等于“撞出”的概率，同时碰撞满足能量守恒。由这两个守恒条件构造线性关系，可以得到：

ln(n_i/g_i) = α - βE_i

指数化：

n_i = g_i e^{α-βE_i}

归一化后：

P_i = [g_i e^{-βE_i}] / Σ_j[g_j e^{-βE_j}]
注意简并度：课件中的“房间数” g_i 会进入统计权重。能级高低决定玻尔兹曼因子，而同一能级有多少个量子态决定简并度。

10.6 为什么量子气体会破坏经典能量均分？

课件最后一句非常重要：自由度均分定理要求各自由度之间的能量能够自由转换；而量子气体中能量转移存在最小阶梯。若 k_BT 小于相邻能级间隔，某些自由度就难以被激发，于是经典均分失效。

模板 A：看到“平衡态分布”

φ(r) → n(r)∝e^{-φ(r)/(kBT)}

模板 D：看到“热容”

数自由度 → 每个二次型贡献 ½kBT → 得 U → 对 T 求导得 C_V

模板 E：看到“实验与经典理论矛盾”

优先想到两个关键词：自由度激发 + 能级量子化。课件中的气体热容、固体热容、黑体辐射都指向这个转折。

自测：不看答案先做

1. 为什么麦克斯韦速率分布中有 v²？
因为速率为 v 的速度矢量位于半径 v 的球壳上，球壳体积与 v²dv 成正比。
2. 一个经典简谐振动模式为什么平均能量是 kBT？
动能和势能各是一个二次型，各贡献 ½kBT，所以总能量为 kBT。
3. 重力场中为什么 n(z) 随高度指数下降？
因为势能 φ=mgz，玻尔兹曼权重为 e^{-φ/(kBT)}，所以 n(z)=n(0)e^{-mgz/(kBT)}。
4. 为什么经典理论预测热容不随温度变化，而实验会变化？
经典均分假设所有自由度都能连续交换能量；量子理论中能级离散，低温时某些自由度无法有效激发，因此有效自由度随温度变化。
5. 为什么“熵最大”与“微观态等概率”不矛盾？
微观态等概率；宏观态的概率还要乘以该宏观态包含的微观态数 Ω。因此 Ω 最大的宏观分布最概然，S=kB lnΩ 最大。
