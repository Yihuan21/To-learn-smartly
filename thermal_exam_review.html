一、考试重点

★★★★★ = 优先掌握
★★★★★ 基础计算

1. 理想气体状态方程

必须会：状态量之间的关系、物质的量与粒子数的转换、状态变化的比例关系。

pV = νRT = NkBT，R = NA kB
识题信号题目给 p、V、T、ν、N 中若干量，求另一量或比较两状态。
举一反三同一气体：ν 不变；同温：pV 不变；同压：V/T 不变；同体积：p/T 不变。
★★★★★ 推导

2. 理想气体压强的微观推导

从分子碰撞器壁的动量变化出发，得到宏观压强与分子平均平方速率的联系。

p = (1/3)nm⟨v²⟩，pV = (1/3)Nm⟨v²⟩
(1/2)m⟨v²⟩ = (3/2)kBT
核心桥梁宏观温度 T ↔ 微观平均动能。
变式若给质量、粒子数、密度或均方根速率，先判断能否由 p=(1/3)nm⟨v²⟩直接求解。
★★★★★ 核心推导

3. 最概然分布 + 拉格朗日乘数

这是第二章最值得完整掌握的一条推导链：等概率原理 → 微观状态数 → 最概然分布 → 指数形式。

Σ aₗ = N，Σ aₗEₗ = E
L = lnΩ − αΣaₗ − βΣaₗEₗ
aₗ ∝ exp(−βEₗ)
识题信号“在总粒子数、总能量等约束下，使状态数最大/概率最大”。
举一反三增加动量、角动量等守恒约束，就增加对应的拉格朗日乘子项。
★★★★★ 分布题

4. Maxwell 速率分布

重点是看懂速度分布与速率分布的区别，以及三种特征速率。

f(v) ∝ v² exp[−mv²/(2kBT)]
vₚ = √(2kBT/m)， v̄ = √(8kBT/πm)， vᵣₘₛ = √(3kBT/m)
必背关系vₚ < v̄ < vᵣₘₛ。
举一反三T 升高 → 分布变宽、峰值向右；m 增大 → 同温下典型速率降低。
★★★★★ 分布

5. Boltzmann 分布

能量越高，占据概率越低；分布由能级差与 kBT 的比值控制。

n(r) ∝ exp[−U(r)/(kBT)]
经典变式重力场 U=mgh → n(h)∝e^(−mgh/kBT)。
再变式谐振势 U=(1/2)kx² → 空间分布呈高斯型。
★★★★★ 工具

6. 配分函数 Z

把所有能级按 Boltzmann 权重加起来，是连接微观能级与宏观热力学量的重要工具。

Z = Σₗ exp(−βEₗ)
识题信号给离散能级、要求求平均能量或热力学量时，优先考虑 Z。
★★★★★ 综合

7. 能量均分 → 内能 → 热容

每个独立二次型自由度平均贡献 1/2 kBT。

⟨E⟩ = (f/2)kBT；U=(f/2)NkBT
Cᵥ,m=(f/2)R；Cₚ=Cᵥ+R
常考单原子 f=3；刚性双原子 f=5。
举一反三振动一个完整谐振模式 = 动能 1/2 kBT + 势能 1/2 kBT = kBT。
★★★★★ 计算

8. 混合气体热容

先分别求各组分物质的量，再把各组分热容相加。

Cᵥ,total = Σ nᵢ Cᵥ,m,ᵢ
易错质量不是物质的量；必须先用 nᵢ=mᵢ/Mᵢ 转换。
★★★★ 状态方程

9. van der Waals 方程与临界点

(p+a/Vₘ²)(Vₘ−b)=RT

a 修正分子间吸引，b 修正分子有限体积。

(∂p/∂Vₘ)T=0；(∂²p/∂Vₘ²)T=0
识题信号“临界点/临界温度/等温线拐点”就想到两个导数条件。
★★★★ 偏导

10. 热学系数

α=(1/V)(∂V/∂T)ₚ；β=(1/p)(∂p/∂T)ᵥ；κ=−(1/V)(∂V/∂p)ₜ
举一反三看到“定压膨胀、定容升压、等温压缩”分别联想到 α、β、κ。
★★★★ 概率

11. 随机游走

⟨x⟩=0；⟨x²⟩∝N；xᵣₘₛ∝√N
高频概念陷阱⟨x⟩=0 不等于每次运动都回到原点；它表示大量实现的平均位移为零。
★★★★ 分布极限

12. 二项分布 → 高斯 / 泊松

P(n)=C(N,n)pⁿ(1−p)ᴺ⁻ⁿ
⟨n⟩=Np；σ²=Np(1−p)
高斯N 很大且 p 不极端时。
泊松N→∞、p→0、Np=λ 固定：P(n)=λⁿe⁻λ/n!。
★★★★ 物理图像

13. Brownian motion / 扩散

D=kBT/(6πηa)
T 越高 → D 越大；黏度 η 越大或粒子半径 a 越大 → D 越小。
★★★ 概念

14. 微观状态、宏观状态、等概率原理

宏观状态由宏观变量描述；一个宏观状态通常对应大量微观状态。平衡条件下，在给定条件下可及微观状态取等概率。

★★★ 概念

15. 固体热容

Dulong–Petit 定律给出高温极限约 3R；低温出现偏离，引出 Einstein / Debye 模型。

★★★ 概念

16. 黑体辐射与紫外灾难

经典 Rayleigh–Jeans + 能量均分在高频端导致能量发散，即“紫外灾难”，说明经典理论在此处失效。

拉格朗日乘数：考试时怎么识别？

只要题目出现“在若干约束条件下，让某个量最大/最小”，就先写目标函数，再把每个约束乘一个待定乘子加入。热学中最典型的是在 Σaₗ=N、ΣaₗEₗ=E 下最大化 lnΩ。

Maxwell 三种速度：为什么顺序是 vp < v̄ < vrms？

它们对应三个不同统计量：峰值位置、速度平均值、平方平均再开方。平方会更强调高速粒子，因此 vrms 最大。

三、15 个母题：会一道，覆盖一类

按考试解题思路组织
01｜两状态理想气体

写 pV=νRT；若气体物质的量不变，直接比较 pV/T。先找“不变量”，通常比逐项代数更快。

02｜van der Waals 临界点

先写 p(V,T)，固定 T，对 V 连续求一、二阶导并同时置零，再联立求临界量。

03｜热学系数

先读题目限定条件：定压→α，定容→β，等温→κ。不要把偏导变量看错。

04｜微观压强推导

沿 x 方向考虑一次碰壁的动量变化，再乘碰撞频率；利用各向同性 ⟨vx²⟩=⟨v²⟩/3。

05｜随机游走

把每一步看成独立随机变量。均值相加，方差也相加，因此位移尺度随 √N 增长。

06｜二项分布

先判断“固定次数 + 每次成功概率固定 + 独立”三个条件；然后直接写二项式。

07｜二项 → 高斯

N 大时用中心极限定性理解；若题目要求数值概率，再标准化 z=(n−Np)/√[Np(1−p)]。

08｜二项 → 泊松

看到“大 N、小 p、平均次数 λ=Np 固定”，立刻换泊松，避免巨大组合数。

09｜微观/宏观状态

先区分“一个宏观状态包含多少微观实现”。平衡时最重要的是寻找微观状态数最多的宏观分布。

10｜最概然分布

写 Ω、取 lnΩ、Stirling 化简、加约束、求偏导、得到指数分布。每一步都有明确目的。

11｜Maxwell 分布

若问“速率范围/最概然速率/平均速率/均方根速率”，不要混淆三者。

12｜三种特征速度

先判断题目关键词：最概然→vp；平均→v̄；均方根→vrms。

13｜Boltzmann 分布

先写 n∝e^(−U/kBT)，再把题目给的势能 U(r) 代入。重力场和谐振势是最典型变式。

14｜能量均分与热容

数自由度 f，再用 U=(f/2)NkBT、Cv=(f/2)NkB；最后根据 Cₚ=Cᵥ+NkB 或摩尔形式 Cₚ,m=Cᵥ,m+R。

15｜综合链题

从 Maxwell 得 ⟨v²⟩ → 平均动能 → U → Cᵥ。遇到综合题，把每一问看成同一条链上的下一步。
